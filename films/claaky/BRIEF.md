# Claaky — film de présentation

## Brief
- Objectif : présenter Claaky, compagnon de Claake Code ; invitation à découvrir l'app.
- Public : développeurs, diffusion réseaux sociaux.
- Format retenu : portrait 1080 × 1350 et paysage 1920 × 1080, 24 secondes, 30 fps ; H.264 / AAC, BT.709, yuv420p, faststart.
- Langue : français. Texte à l'écran, sans voix off ; aucune musique, aucun son (demande utilisateur).
- Identité : crème, vert du logo, fond sombre chaleureux. Géométrie de Claaky reprise du composant réel `src/components/claaky/ClaakyScene.tsx` ; logo fourni dans `src/assets/claakecode-logo.png`.
- Trois directions : démonstration d'interface ; comédie de personnage ; portrait éditorial 3D. Direction retenue : portrait éditorial 3D, chaleureux et squishy, quelques détails de code explicitement illustratifs.
- Message central : « Vous lui parlez. Claaky code avec vous. »
- Vérité produit : compagnon, poses réflexion/travail/fin, accueil « Que faisons-nous ? », réglage désactivable. Aucun résultat de code inventé présenté comme une vraie exécution.
- Aucune annonce de disponibilité/version : publication de v0.1.71 non vérifiée.
- Licences : assets de marque utilisateur ; modèle dérivé de son code ; audio original. Pas de référence vidéo copiée.
- Livrable final : `out/final.mp4`, projet reproductible avec `window.seek(t)`.
- Étape courante : quatre images clés à valider avant rendu complet.
