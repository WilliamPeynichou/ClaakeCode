New in v0.1.68 · experimental

A second chat that keeps its state.

The RLM chat runs the open-source Prime Agent engine in its own tab, next to Chat: an agent with a persistent Python kernel, working in its own git worktree. One click on Auto Compute hands any agent chat over to it.

01 · Chat | RLM

A tab next to Chat,its own history.

Open the RLM tab at the top of the chat panel. It keeps its own list of conversations and uses the same model picker, sign-ins and API keys as the classic chat: Anthropic and OpenAI accounts, OpenRouter and Mistral keys.

02 · Auto Compute

Hand a chat over,let it compute.

Press Auto Compute in an agent chat: a new RLM chat opens on the same model, receives the conversation and starts checking, measuring and re-running what it needs in Python. The original chat stays untouched.

03 · Isolated worktree

Its own branch.Your files untouched.

Each RLM conversation gets a git worktree on a claakecode/rlm-… branch. A banner says it plainly: the agent runs locally with your permissions, there is no sandbox.

04 · Persistent Python

Variables survivebetween messages.

Load data once, reuse it three questions later. The Python persistant page in Settings shows the engine state, Python version, size, location and every installed package, with a restart button.

05 · Resumes after a cut

Connection drops?The answer still lands.

Claake Code reattaches to the running turn, fills the gap from Prime's snapshot without duplicating text, and never sends your prompt twice. Conversations reopen with their history after a restart.

Engine

Prime Agent 0.9.8, open source, pinned to a reviewed commit and bundled with the app.

Platforms

macOS and Linux. Windows shows the RLM chat as unavailable for now.

Providers

Anthropic, OpenAI, OpenRouter, Mistral. Google sign-in is not supported in RLM yet.

Status

Experimental. Needs a git repository with at least one commit. Auto Compute hands over the text of the chat, not tool results.
