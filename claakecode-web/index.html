New in v0.1.67 · experimental

A second chat that keeps its state.

The RLM chat runs the open-source Prime Agent engine next to the classic chat: an agent with a persistent Python kernel, working in its own git worktree.

  1. 01
  2. 02

01 · Same models

Next to the classic chat,not instead of it.

Open one with the RLM button. It uses the providers you already connected: Anthropic and OpenAI sign-ins, OpenRouter and Mistral keys. Prime only receives short-lived access tokens, never refresh tokens.

02 · Isolated worktree

Its own branch.Your files untouched.

Each RLM conversation gets a git worktree on a claakecode/rlm-… branch. A banner says it plainly: the agent runs locally with your permissions, there is no sandbox.

03 · Persistent Python

Variables survivebetween messages.

Load data once, reuse it three questions later. The Python persistant page in Settings shows the engine state, Python version, size, location and every installed package, with a restart button.

04 · Resumes after a cut

Connection drops?The answer still lands.

Claake Code reattaches to the running turn, fills the gap from Prime's snapshot without duplicating text, and never sends your prompt twice. Conversations reopen with their history after a restart.

Engine

Prime Agent 0.9.8, open source, pinned to a reviewed commit and bundled with the app.

Platforms

macOS and Linux. Windows shows the RLM chat as unavailable for now.

Providers

Anthropic, OpenAI, OpenRouter, Mistral. Google sign-in is not supported in RLM yet.

Status

Experimental. Needs a git repository with at least one commit.
