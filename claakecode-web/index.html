03 / RLM Prime

Un second chat.
Un état qui reste.

Un Python persistant pour décomposer une tâche et réutiliser ses résultats.

Moteur
Prime Agent · Expérimental
Espace
Historique et worktree distincts
Disponibilité
macOS et Linux uniquement
03
CLAAKE CODE — 03
RLM Prime03 / 06

Continuer.

Les variables Python restent disponibles entre les exécutions d’une même session RLM. Auto Compute transmet du contexte depuis le chat classique. Un dépôt Git avec au moins un commit est requis. Fournisseurs pris en charge : Anthropic, OpenAI, OpenRouter et Mistral. Un worktree sépare les fichiers, pas les permissions : ce n’est pas un bac à sable de sécurité. Les tâches longues et le mode Goal restent à vérifier manuellement avec un vrai modèle.

Les leçons05 / 06

Retenir.

Une leçon conserve une règle et ses preuves. Le banc de test compare de petites tâches avec et sans leçon, notamment sur le moteur RLM. Le parcours complet avec un vrai modèle reste à valider : il ne prouve pas un gain général sur vos projets. Vous pouvez désactiver le rappel des leçons dans les réglages. Les coûts affichés sont des estimations, pas une facture.

Questions utiles

Avant de commencer.

Qu’est-ce qui est gratuit ?

Le code est sous licence MIT. Les frais, quotas et conditions de vos fournisseurs de modèles s’appliquent.

Les modèles fonctionnent-ils hors ligne ?

Les requêtes et le contexte utile sont envoyés aux services configurés. Le terminal et les serveurs MCP peuvent aussi accéder au réseau.

RLM fonctionne-t-il sous Windows ?

Non. RLM Prime est expérimental et disponible sur macOS et Linux. Il prend en charge Anthropic, OpenAI, OpenRouter et Mistral.

L’agent peut-il travailler sans surveillance ?

Il peut enchaîner des étapes, sans garantir le résultat. Limitez ses permissions et vérifiez ses modifications. Un worktree Git n’est pas un bac à sable de sécurité.
