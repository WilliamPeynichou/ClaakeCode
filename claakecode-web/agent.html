§ 01 — how the agent works

Plan. Act. Observe.
Reflect. Repeat.

The same loop runs across providers. After each tool call, the agent re-reads the world, scores progress against the plan, and decides whether to continue, branch, ask or stop.

01

Plan

Break the objective into understandable steps — or enter Plan mode for a functional plan first.

→
02

Act

Use only approved tools: edit files, run tests, query data, call MCP or delegate.

→
03

Observe

Read file diffs, shell output, schema metadata, web pages or teammate updates.

→
04

Reflect

Update the task board, clean context if useful, then loop until done.
