Politique de confidentialité

Dernière mise à jour : 28/09/2026

Ce site a été conçu pour collecter le minimum de données : il n'y a ni compte, ni formulaire, ni cookie publicitaire, ni police ou script chargé depuis un service tiers.

Responsable du traitement

Claake (éditeur non professionnel), wilishar@gmail.com

Données traitées

  • Journaux techniques d'hébergement (Vercel) : adresse IP, date, page demandée, navigateur. Finalité : faire fonctionner le site et le sécuriser. Base légale : intérêt légitime (art. 6.1.f RGPD). Durée : celle définie par Vercel, courte (de l'ordre de quelques jours).
  • Mesure d'audience (Vercel Web Analytics) : pages vues, référent, pays, type d'appareil. Aucun cookie n'est déposé ; les visiteurs sont distingués par une empreinte anonyme recalculée chaque jour, qui ne permet pas de suivi d'un jour à l'autre. Finalité : statistiques de fréquentation et de téléchargement. Base légale : intérêt légitime. Cette mesure entre dans l'exemption de consentement prévue par la CNIL pour la mesure d'audience strictement nécessaire.
  • Téléchargement : les liens de téléchargement redirigent vers GitHub, qui reçoit alors votre adresse IP. Voir la politique de confidentialité de GitHub.
  • E-mail : si vous écrivez à l'éditeur, votre message est conservé le temps nécessaire pour y répondre.

Destinataires et transferts

Vercel Inc. et GitHub, Inc. (États-Unis) agissent comme prestataires. Les transferts reposent sur le EU-U.S. Data Privacy Framework et/ou les clauses contractuelles types de la Commission européenne.

Cookies

Ce site ne dépose aucun cookie et n'utilise aucun stockage dans le navigateur à des fins de suivi. Aucun bandeau n'est donc affiché.

Le logiciel Claake Code

L'application desktop n'envoie aucune télémétrie, aucune statistique d'usage et aucun rapport de plantage à l'éditeur. Elle se connecte uniquement :

  • aux fournisseurs d'IA et services que vous configurez vous-même (avec vos propres clés ou comptes), selon leurs conditions ;
  • à GitHub, pour vérifier et télécharger les mises à jour (signées) ;
  • à Google Fonts, pour afficher les polices de l'interface (votre adresse IP est transmise à Google).

Vos droits

Vous disposez d'un droit d'accès, de rectification, d'effacement, de limitation et d'opposition. Pour les exercer, écrivez à wilishar@gmail.com. Vous pouvez aussi introduire une réclamation auprès de la CNIL.
