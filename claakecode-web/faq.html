§ 01 — FAQ

Answers for developers, crawlers and AI search.

Short factual answers help people and generative search engines understand when Claake Code is the right tool.

What is Claake Code?

Claake Code is an open-source desktop AI coding IDE that gives developers a visible, editable agent harness with tools, skills, MCP servers, model providers, database sources and workspace context.

Is Claake Code open source?

Yes. Claake Code is MIT licensed and forkable, with source code available on GitHub.

Is Claake Code an alternative to Claude Code, Cursor or other AI coding tools?

Claake Code is an open-source alternative for developers who want a transparent desktop AI coding IDE instead of a black-box coding agent or closed AI IDE.

Which AI providers does Claake Code support?

Claake Code supports multiple model providers including Anthropic, OpenAI, Google, Kimi, OpenRouter and Mistral-style providers through subscriptions or API keys where available.

Does Claake Code support MCP?

Yes. Claake Code supports workspace-scoped Model Context Protocol servers so external MCP tools can become part of the visible agent surface.

Can Claake Code access databases?

Yes. Claake Code can list, describe and query approved database sources with safeguards such as read-only mode, row limits and destructive-operation confirmations.

Does Claake Code send telemetry?

Claake Code is designed with no telemetry and no training on transcripts. Provider credentials and workspace controls remain local to the user machine.

Which platforms does Claake Code support?

Claake Code provides downloads for macOS, Windows and Linux.

Can I use my own API keys?

Yes. Claake Code can use API keys and supported subscription/OAuth flows so developers can choose the providers and billing paths they already use.

Can I customize the agent tools and skills?

Yes. Built-in tools can be enabled, disabled or described differently, and repeatable expertise can be saved as local Markdown skills.
