# Security Policy

## Reporting a vulnerability
Please do **not** open a public issue. Report privately via
[GitHub Security Advisories](https://github.com/WilliamPeynichou/ClaakeCode/security/advisories/new)
or by e-mail to wilishar@gmail.com.

We aim to acknowledge reports within 7 days. Coordinated disclosure is appreciated.

## Supported versions
Only the latest release receives security fixes.
